# Figma Design Workflow

Use this route only when a Figma connector is available and the user wants a screen created or updated in Figma. If the connector is unavailable, state that limitation instead of pretending to edit the design file.

Before editing, identify the target file, page, target screen, and its published design system. Reuse existing components, variables, text styles, and effect styles. Do not recreate a known system with hard-coded rectangles or one-off style values.

Build a screen section by section. Confirm the page structure and component instances before spending time on visual polish. When a running web app is available, use a screenshot of the implementation as a visual comparison target while preserving linked Figma components and variables.

Use the Figma-specific implementation workflow for code generation from a design file; this route covers authoring and updating the Figma screen itself.
