# Design Direction

Establish a specific, product-appropriate visual thesis before implementation. For a new interface, identify the audience, job, tone, one memorable visual decision, and technical constraints. For an existing interface, preserve its recognizable structure and improve only the surface in scope.

Choose one coherent direction and execute it consistently:

- Let typography, spacing, composition, color, and motion support the same product character.
- Use a deliberate layout rhythm rather than a predictable stack of identical modules.
- Prefer a dominant visual anchor when the page calls for one.
- Use CSS variables or existing tokens for repeated visual values.
- Match technical complexity to the visual direction. Refinement often means fewer, better choices.

Avoid generic palettes, cookie-cutter card grids, filler copy, and decoration that does not clarify interaction, content, or brand. Do not replace an established product system merely because it is restrained or uses common fonts.

After implementation, inspect a rendered screenshot. Correct composition, hierarchy, type scale, density, spacing, color relationships, and responsive behavior before treating the work as complete.
